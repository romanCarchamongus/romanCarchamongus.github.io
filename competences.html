Concordia : réaliser une version informatique d'un jeu de plateau complexe

Le jeu Concordia est un jeu de plateau stratégique où les joueurs doivent développer leur empire commercial dans l'Empire romain. Nous étions par équipe de 5 à 8 étudiants (5 pour mon équipe) et l'objectif était de permettre à un joueur de jouer contre des ordinateurs.

L'architecture MVC et le langage Python nous ont été imposés pour ce projet. Nous avons dû concevoir différents diagrammes (diagramme de cas d'utilisation, diagramme de classes, diagramme de séquence), utiliser plusieurs design patterns et effectuer des tests. Le dernier jour, nous avons mené une soutenance et une démo du résultat.

Technologies :

Python Oracle MVC

Application Web pour répondre à un besoin spécifique

Par équipe de 5 à 6, notre objectif était de créer une application web pour organiser des compétitions de foot de robot. L'aplication devait permettre aux utilisateurs de créer et organiser des compétitions, d'inscrire des équipes, de gérer les matchs et de visualiser les résultats.

Nous avons utilisé le framework Symfony pour le développement de l'application, avec une base de données MySQL pour stocker les informations. Il s'agit également du premier projet où l'accent a été mis sur le management agile. Nous avons suivi la méthode Scrum avec des démos régulières pour présenter l'avancement du projet.

Technologies :

PHP Symfony MySQL

Application de création de graphiques pour l'analyse de données

Ce projet a débuté à la fin de ma première année et était notre premier gros projet, ayant pour objectif de rassembler toutes les compétences acquises au cours de l'année. Nous avons travaillé par équipe de 5 à 6 étudiants en partant d'un cahier des charges pour créer une application permettant de créer des graphiques à partir d'un jeu de données.

Pour la visualisation des données, nous avons utilisé Python avec la bibliothèque Matplotlib pour créer différents graphiques (régression linéaire, histogrammes...). L'interface utilisateur a été développée en C# avec Windows Forms. Nous avons également utilisé MySQL pour stocker les données et effectuer des requêtes pour récupérer les informations nécessaires.

Technologies :

Python C# MySQL

IMH : développement d'un jeu en .Net

Ce projet a été ma première expérience avec le langage C# et l'environnement de développement Visual Studio. Notre objectif était, à partir d'un code fournit, de développer un jeu typé "Tower Defense". Toute la partie graphique était déjà partiellement complétée, mais nous avons dû coder la logique derrière le jeu.

Ce projet était par équipe de 3 et était l'un de nos premier projet de programmation, durant lequel j'ai notamment été amené à implémenter l'algorithme de dijkstra.

C# Visual Studio
